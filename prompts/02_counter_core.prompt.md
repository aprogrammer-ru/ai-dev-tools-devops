Реализуй: "Counter core (Redis + Postgres)".

Ограничения:
- Не трогай CI/CD, observability и алерты.
- Добавляй только то, что нужно для атомарного ядра счетчика.

Сделай:
1. Реализуй атомарный инкремент значения в Redis (`INCRBY` или Lua при необходимости).
2. Реализуй персистентную запись состояния в Postgres.
3. Добавь миграции БД (Alembic):
   - таблица `counters`
   - таблица для идемпотентности/аудита (`idempotency_records` или эквивалент).
4. Добавь индексы и ограничения целостности для этих таблиц.

Критерий готовности:
- При инкременте значение атомарно растет в Redis и фиксируется в Postgres.
