Реализуй: "Скелет сервиса и доменная модель" для распределенного счетчика.

Ограничения:
- Выполняй только этот шаг, не переходи к следующим.
- Стек: Python 3.12, FastAPI, Pydantic v2.
- Конфиг только через env (pydantic-settings).

Сделай:
1. Создай каркас FastAPI-приложения.
2. Добавь базовые контракты запросов/ответов.
3. Добавь endpoint'ы:
   - `GET /health/live`
   - `GET /health/ready`
   - `GET /v1/counters/{key}`
   - `POST /v1/counters/{key}/increment` (без полной бизнес-логики, только валидный каркас).
4. Подготовь структуру модулей под будущую бизнес-логику (services/repositories/schemas/settings).

Критерий готовности:
- Приложение стартует и health endpoint'ы отдают 200.
