Реализуй: "Надежность API".

Ограничения:
- Не внедряй метрики/дашборды/деплой.
- Работай только с надежностью запросов.

Сделай:
1. Добавь поддержку `Idempotency-Key` для `POST /v1/counters/{key}/increment`.
2. Реализуй хранение результата идемпотентного запроса (Redis + Postgres, с TTL в Redis).
3. Добавь rate limiting на клиент/ключ.
4. Добавь предсказуемую обработку ошибок:
   - валидация входных данных
   - 404 для отсутствующего счетчика
   - 429 для превышения лимита
   - безопасные 5xx с логированием причины.
5. Добавь retry/backoff только для transient-сбоев инфраструктуры (Redis/Postgres).

Критерий готовности:
- Повторный запрос с тем же `Idempotency-Key` не инкрементирует счетчик повторно.
